# Проверка спецификации создания Task и чатов

13 ноября 2026. Проверены [спецификация](tracker-task-chat-spec.md), [сценарий оператора](task-review-journey.md), код доски на `346d474` и локальный протокол App Server. Требования к названию однозначны. Оба шаблона используют ключ тикета и полное сохранённое название родительской Task. Отдельное поле проекта не требуется.

Такой тест проходит и при опечатке в конфиге. | Проверять ID модели по каталогу до создания, затем проверять фактический выбор в Desktop. ## Готовность

Можно начинать с формы создания Task. Для чата разработки есть проверяемый путь через общий App Server. Перед выпуском требуются проверка чтения Трекера от имени процесса сервиса и сквозная проверка открытия из браузера в установленный Desktop. Изолированный тест подтверждает создание пустого чата и воспроизводит ошибочный критерий для модели. Он не проверяет полномочия сервиса и поведение поля ввода на экране. Порядок внедрения и проверки описаны в [плане](tracker-task-chat-plan.md).
